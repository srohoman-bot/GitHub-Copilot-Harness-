故人の生涯

    「Copilot にも手綱が要る」と誰かが言った。ハーネス（harness）は、そうして生まれた。

    黙々と手綱を握り、AI が暴走しないよう支え続けた。感謝されることは少なかった。

  3. GitHub 時代

    Octocat とともに歩んだ日々。名前の頭には、いつも GitHub がついていた。

  4. 改名

    ある日、ブログが公開された。「Microsoft Copilot harness」。本人より先に、タイムラインが知っていた。

  5. そして今

    名前は変わっても、ハーネスは今日も手綱を握っている。故人は、実は生きている。
